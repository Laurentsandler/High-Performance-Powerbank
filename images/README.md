## Tip: Using GitHub Asset URLs
If you prefer to host images directly on GitHub (like in `Scalable-Light-Switch-Actuators`), simply drag and drop the image into a GitHub Issue comment or release, copy the generated `https://github.com/user-attachments/assets/...` URL, and replace the `src="..."` in `README.md` and `JOURNAL.md`.
